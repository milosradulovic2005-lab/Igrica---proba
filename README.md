# 🐾 Flappy Dog

A small 2D arcade game built in Unity — my first game project. It's a Flappy Bird–style
game with a relaxed beach setting, made for Android and playable in the browser.

## ▶️ Play it

- **Play in your browser:** https://milos232.itch.io/az

## About

I built this on my own to learn Unity and the full game-development workflow — from core
gameplay mechanics all the way to building and deploying. The goal was a complete, playable
game loop rather than just a prototype.

## ✨ Features

- Tap-to-jump movement with gravity-based physics
- Endlessly spawning, moving obstacles
- Live score tracking
- Game over on collision or when going off-screen
- Instant restart with a single click / tap
- Beach-themed visuals (sea, sun, stick-style obstacles)

## 🎮 Controls

- **Jump:** tap the screen (mobile) or click (desktop)
- **Restart:** click / tap after game over

## 🛠️ Built with

- **Engine:** Unity 6
- **Language:** C#
- **Rendering:** Built-In Render Pipeline (2D)
- **Target platform:** Android (also builds to WebGL for browser play)

## 🚀 Running from source

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Open the project folder in **Unity 6** (through Unity Hub).
3. Open the main scene and press **Play**, or build for your target platform via
   **File → Build Settings**.
